# Logic Escape XR

**Team:** Muhammad Ashhad Siddiqui (Individual Project)

## My Idea

I want to build an educational VR escape room game that teaches players how logic gates work. The player is trapped in a futuristic laboratory and must solve puzzles using AND, OR and NOT gates to unlock doors and eventually escape.

Some puzzles will involve changing the inputs of a gate using switches to get the required output. In others, the inputs will be fixed, and the player will have to choose the correct logic gate and place it into an empty slot to complete the puzzle.

## How Players Will Learn

The aim is to teach players how different logic gates work, how their inputs affect their outputs, and how to use them to solve simple problems.

The game will start with guided examples of AND, OR and NOT gates, followed by puzzles where players apply what they have learned. Players will be able to experiment with switches and see the output change through lights. Incorrect solutions will provide feedback, while correct solutions will unlock the next area.

The final challenge will involve using multiple gates together to solve a more difficult puzzle.

## Development Plan

I'll start with a basic VR room, working switches and a door that unlocks when the correct output is produced. I'll then add the different logic gates, puzzles involving placing gates into slots, and a final challenge combining multiple gates.

If time allows, I may add more gate types such as XOR and NAND, along with improvements to the visuals and sound.

## Technologies

- **Godot 4 and GDScript** for the 3D environment, logic gate puzzles and door mechanics.
- **OpenXR** for running the game on a Meta Quest VR headset.
- **Godot XR Tools** for controller interactions, including pressing switches and grabbing and placing logic gates.
